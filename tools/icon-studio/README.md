# DoodlebookOS — Icon Studio

A native PySide6 and QML tool designed for personalizing desktop applications, Progressive Web Apps (PWAs), and launcher icons within the Material 3 Expressive design language.

## Features

- **PWA & Web App Detection:** Automatically identifies web apps and PWAs from Chrome, Chromium, Brave, and web browsers.
- **Icon Extraction & Replacement:** Easily assign custom icons or restore defaults.
- **Instant System Cache Refresh:** Directly updates KDE Plasma application cache via `kbuildsycoca6`.

## Usage

Run from terminal or your application launcher:

```bash
doodlebook-icon-studio
```
